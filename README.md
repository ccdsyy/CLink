## 🎮 三步联机（保姆级）

### 房主

1. 打开 Minecraft，进入单人世界，按 `Esc` → **「对局域网开放」**
2. 打开 CLink，点 **「创建房间」**（端口会自动识别）
3. 把自动复制的 **6 位房间码** 发给你的小伙伴

### 客机（小伙伴）

1. 打开 CLink，输入房间码
2. 点 **「一键加入」**
3. 显示"连接成功"后，回到游戏：**多人游戏 → 直接连接 → 粘贴**（`127.0.0.1:25565` 已自动复制）

就这么简单。🎉

## 🧠 CLink 在底层做了什么

CLink 内置**三层智能网络**，自动选最快的方式把你们连起来：

| 层级 | 方式 | 什么时候用 |
|------|------|-----------|
| ⚡ Tier 1 | **IPv6 极速直连** | 双方网络都支持 IPv6（国内运营商大范围普及中） |
| 🛟 Tier 2 | **WebRTC P2P 打洞** | 普通宽带/校园网（UDP NAT 穿透） |
| 🆘 Tier 3 | **兜底指引 + 自定义中转** | 双方都是对称型 NAT 时，提示切换手机热点；技术党可勾选公共 TURN 或自建中转 |

**信令交换**不依赖任何 Token 和账号：借用国内公共"剪贴板"服务完成加密信件投递，
所有信件**端到端加密（AES-256-GCM）**，密钥由房间码派生——服务器只保管一个谁也打不开的保险箱。

**信令服务器支持多节点容灾**（设置 → 网络与信令）：

- 默认「自动容灾」：**剪贴板服务1**（paste.sdjz.wiki）→ **UAPI剪贴板服务**（uapis.cn 网关）依次轮换，一个挂了自动切下一个
- 也可以手动锁定某个节点，或填自部署的同协议后端

**STUN 打洞节点多节点选优**：内置 Google / 小米 / Cloudflare / Nextcloud 公共 STUN。
实测国内 CGNAT 环境下多节点候选会互相干扰，所以 CLink 的做法是
**并发探测全部节点选最快可用者，ICE 只挂最优单节点**（节点挂掉自动换），
稳定性和容灾兼得。TURN 中继支持勾选公共预设节点 + 自建 coturn。

> 打开 CLink 的"网络体检"可以随时查看自己家的网络属于哪一层、命中了哪个 STUN 节点。

## ✨ 其他贴心功能

- 🔗 **连接质量徽标**：连上显示「连接方式 · 延迟 · 双方 NAT 类型」，网络好坏一目了然
- 🕘 **最近房间**：最近用过的房间码一键回填，重连不用翻聊天记录
- 📋 **一键复制邀请文案**：房间码 + 下载链接一条消息发朋友
- 👋 **掉线感知**：有小伙伴掉线房主立刻知道（成员列表 + 系统通知）
- 🔌 **自定义本地端口**：自己电脑上开着 MC 服务器也不冲突
- 🖥️ **LAN 秒连**：同一局域网自动发现房主，跳过一切信令直连
- 🛣️ **五级路径竞速**：LAN → UPnP 公网直连 → IPv6 → P2P 打洞 ∥ 自建中继，谁快用谁，永不"卡在正在连接"
- 🔓 **UPnP 自动开图钉**：路由器支持时自动映射公网端口（PCP/NAT-PMP/UPnP 三连试 + 实测验证）
- 📡 **自建中继**：单文件 `clink-relay` 部署到任意 VPS，对称 NAT 兜底自己说了算（HMAC 鉴权，端到端加密）
- 🎮 **游戏内体验**：隧道建立中时游戏服务器列表显示 MOTD 提示，不再黑屏报错
- 🛠️ **开放 IPC**：127.0.0.1:42656 JSON 协议，启动器/第三方 Mod 可直接调用穿透栈
- 🛡️ 黑名单防骚扰 · 📮 短信盒子提醒 · 🧩 Modrinth 模组直连下载 · 🧰 IP 归属地 / MC 服务器状态 / 二维码工具箱

## ❓ 常见问题

<details>
<summary><b>小伙伴一直"正在连接"怎么办？</b></summary>

多半是双方都在对称型 NAT 后面（部分校园网/企业网）。让**一方**切换到**手机热点**再试，成功率立竿见影。也可以在「设置 → 网络与信令」勾选公共 TURN 中继节点试试（社区免费节点不保证可用），有服务器的话推荐自建 coturn。
</details>

<details>
<summary><b>防火墙弹窗要点允许吗？</b></summary>

要。CLink 需要接收来自小伙伴的入站连接，Windows 防火墙规则会由程序自动添加（需一次 UAC 授权）。
</details>

<details>
<summary><b>房间码安全吗？会被陌生人闯入吗？</b></summary>

房间码 6 位、约 8.9 亿种组合，且房间只保留 6 小时。信箱内容端到端加密，连信箱服务器自己都看不到你们的连接信息。知道房间码 = 是房间成员，这是设计使然（就像知道密码 = 能进门）。
</details>

<details>
<summary><b>支持多少人？</b></summary>

同一房间支持最多 31 位小伙伴**依次**加入（同时加入会自动排队重试）。房主退出程序 = 房间关闭。
</details>

<details>
<summary><b>会泄露我的 IP 吗？</b></summary>

P2P 直连的本质是双方交换网络地址后建立连接，对等端互相可见（这是所有联机工具的共性）；对第三方（信箱服务器）我们只投递加密信封。介意隐私的用户请自建 TURN。
</details>
